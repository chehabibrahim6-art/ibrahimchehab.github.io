=====================================

Files
-----
index.html                 Main webpage
styles.css                 Visual design and responsive layout
script.js                  Lightweight navigation interaction
Ibrahim_Chehab_Resume.pdf  Resume download link used by the site

How to use
----------
1. Keep all four files in the same folder.
2. Open index.html in a browser to preview the website.
3. For a public URL, upload the folder to a static host such as GitHub Pages or another class-approved web host.

Assignment alignment
--------------------
- Digital resume rather than a paper-only format
- Internal navigation through section hyperlinks
- Search-friendly title and meta description
- Professional visuals and page structure
- Portfolio/project descriptions using engineering terminology from the resume
- External links to University of Michigan-Dearborn and SAE Formula SAE resources
- Accessible skip link, semantic sections, descriptive labels, keyboard-friendly links, and responsive design

Content note
------------
The personal experience, skills, education, and project details are based on the September 2026 resume provided for the assignment. The external program links were included to give readers context for the academic and Formula SAE experience.
